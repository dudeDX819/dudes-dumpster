# Last Survivor Standing

Reimplementa a mecânica do "Último Homem na Terra" de se reviver quando estiver sozinho em campanha.

Reimplements the self-revive mechanic from "Last Man on Earth" when alone in co-op.

<img width="800" height="800" alt="ezgif-609b2824e3a80968" src="https://github.com/user-attachments/assets/a7b1de59-a118-41fe-bef8-daf1ae3dac8e" />

**CVARS**
> cfg/sourcemod/l4d2_lastsurvivorstanding.cfg
```
l4d2_lss_enable - Ativa/desativa o plugin // Enables/disables the plugin. (0/1, default: 1)
l4d2_lss_temp_health - Quantidade de vida temporária ao reviver // Temporary health amount on revive. (0-99, default: 99)
l4d2_lss_ignore_time - Tempo de imunade do último sobrevivente em segundos // Last Survivor's immunity time in seconds. (-1/0/X, default: 6)
```

**Requisitos / Requirements**
> [Sourcemod 1.11+](https://www.sourcemod.net/downloads.php?branch=stable)
