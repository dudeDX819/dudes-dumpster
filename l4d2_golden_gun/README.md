# Golden Gun

Te da uma Magnum com uma bala insta-kill via comando de Admin.

Gives you an one bullet one-shot kill Magnum via Admin command.

<img width="300" height="300" alt="ezgif-43053bfb946c9f6a" src="https://github.com/user-attachments/assets/0e6d42f3-c964-483f-950c-9927e606a0ca" />

**Comandos / Commands**
> Flag: ADMFLAG_GENERIC (b)
```
!admingun / sm_admingun - Te da a arma dourada // Gives you the golden gun.
!golden / sm_golden - Te da a arma dourada // Gives you the golden gun.
!goldengun / sm_goldengun - Te da a arma dourada // Gives you the golden gun.
```

**Requisitos / Requirements**
> [Sourcemod 1.11+](https://www.sourcemod.net/downloads.php?branch=stable)
