# Quick Melee

Permite que você de um ataque rapido corpo a corpo que nem no Call of Duty.

Allows you to do a quick melee attack just like in Call of Duty.

<img width="500" height="500" alt="ezgif-7f77212600e8ccd7" src="https://github.com/user-attachments/assets/caf6afff-e42f-46e7-bd6c-1abd5d2d6350" />

**Comandos / Commands**
> Flag: None.
```
!qmelee / sm_qmelee - Executa um ataque corpo a corpo rápido. // Performs a quick melee attack.
 // 
```

**Requisitos / Requirements**
> [Sourcemod 1.10+](https://www.sourcemod.net/downloads.php?branch=stable)
